\subsection{General approach}
We focus on employing Deep Q Learning (DQN) to solve the Sokoban puzzle. DQN belongs to a category of artificial neural networks designed to approximate the optimal Q-value function within the framework of Reinforcement Learning. The Q-value function maps states to action values, indicating the expected reward obtained when taking a specific action in a given state. 

The network is trained using a mix of supervised and reinforcement learning. It calculates the difference between predicted Q-values and actual rewards from the environment as its loss function. The DQN algorithm updates the network iteratively using batches of experiences from a replay buffer, following the Bellman equation:

\begin{equation*}
Q(s, a) = \sum_{s'} P(s' \,|\, s, a) \left[ R(s, a, s') + \gamma \max_{a'} Q(s', a') \right]
\end{equation*}

This equation calculates the reward for an action \(a\) in a given state \(s\). It considers the resulting state, \(s'\), the probability of reaching this state (\(P(s' | s, a)\)), the immediate reward obtained (\(R(s, a, s')\)), and the importance of future rewards (\(\gamma\)). The maximization step helps identify the best possible outcome from the subsequent situation.
